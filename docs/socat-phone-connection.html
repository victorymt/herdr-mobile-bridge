先记住一句话 返回目录 ↑

手机不直接连接 Herdr，也不直接连接 Unix socket。socat 只负责把电脑某个局域网地址上的 TCP 端口，逐连接转发到本机的 Bridge HTTP 端口。

因此它适合“同一可信 Wi‑Fi 下临时使用”：配置简单、无需改 Bridge 的监听地址，但它本身不提供 HTTPS，也不替你完成登录认证。

准备工作 返回目录 ↑

  1. 确认电脑和手机在同一个可信局域网。
  2. 启动插件并生成配置：
    node src/launcher.js setup
node src/launcher.js status
node src/launcher.js token
  3. 确认 Bridge 正常监听：
    curl -fsS http://127.0.0.1:8787/healthz
    返回 JSON 且 ok:true。
  4. 找出电脑的 LAN IPv4 地址，例如 192.168.1.20。Linux 可用 ip addr 或桌面网络设置查看。

不要把 127.0.0.1 填到手机浏览器里；它在手机上指的是手机自身。

运行 socat 返回目录 ↑

在电脑上执行（把地址替换成电脑自己的 LAN 地址）：

socat TCP-LISTEN:18787,bind=192.168.1.20,reuseaddr,fork TCP:127.0.0.1:8787
参数含义
TCP-LISTEN:18787在电脑的 18787 端口监听手机连接。
bind=192.168.1.20只绑定这块 LAN 网卡，不监听所有接口。
reuseaddr允许快速重启时复用端口。
fork每个手机连接派生一个处理进程。
TCP:127.0.0.1:8787把流量送到本机 Bridge。
验证端口：先在电脑执行 curl http://192.168.1.20:18787/healthz，再在手机浏览器打开 http://192.168.1.20:18787。

手机端登录和使用 返回目录 ↑

  1. 打开 http://192.168.1.20:18787。
  2. 输入 node src/launcher.js token 打印出的 Bridge token。
  3. 登录成功后即可查看状态、最近输出、聚焦窗格、发送任务和交互输入。
  4. 使用“开启提醒”需要浏览器支持 Web Push；普通局域网 HTTP 通常无法启用推送，这是浏览器安全策略，不是 socat 故障。

登录后浏览器用 Cookie 保存会话；写操作还会附带 CSRF token。socat 只转发字节流，不会绕过这些认证检查。

安全边界 返回目录 ↑

这是 HTTP 明文转发。同一网络中具备抓包能力的人可能看到请求内容；不要在公共 Wi‑Fi、酒店网络或不受信任的办公网使用。
  • 仅绑定电脑的 LAN IP，不要用 0.0.0.0。
  • 开启主机防火墙，仅允许可信网段访问 18787。
  • 用完后在运行 socat 的终端按 Ctrl+C 停止。
  • 不要把 18787 端口做路由器端口映射或暴露到公网。
  • socat 是外部透明转发，不会执行 Bridge 的内置 CIDR ACL；使用它时必须在 socat 所在主机的防火墙或受信反向代理中重复限制来源。
  • 内置 Node proxy 可配置 lanProxyAllowedCidrs（省略表示关闭 ACL），拒绝连接会直接关闭 TCP，不会返回 HTTP 403。
  • Bridge 默认以令牌桶限制 API（120 次/分钟、突发 30），登录另有每来源 5 次/分钟限制；超限返回 429 和 Retry-After。
  • 请求体默认必须在 10 秒内完成（最大可配置 60 秒）；超时返回 408 request_body_timeout。
  • 需要手机通知时，可使用仅绑定 LAN/VPN 地址的 HTTPS 反向代理，并在 bridge.json 配置准确的 allowedOrigin 与 cookieSecure:true。修改 ACL、限流或超时后要先停止旧 Bridge，再重新执行 launcher。

排错清单 返回目录 ↑

现象优先检查
手机无法打开页面电脑 LAN IP 是否正确；socat 是否仍在运行；防火墙是否放行 18787；两台设备是否在同一网段。
电脑 curl 成功，手机失败是否绑定到了错误网卡；路由器是否启用了客户端隔离（AP isolation）。
页面能开但显示 Herdr 不可用执行 node src/launcher.js status，确认 socket_present:true，并检查 Herdr 会话是否在运行。
登录失败重新执行 node src/launcher.js token；确认访问的是当前配置对应的 Bridge。
提醒无法开启这是 HTTP 环境，改用 HTTPS 反向代理；控制功能仍可继续使用。
